# おうちの燃費チェック（かんたん版）― 公開用の簡易版

`passive_house_calc/`（フル版：特定の相手に配布）の計算エンジンをそのまま使い、入力を5問に絞った
誰でも使える公開用の簡易版です。`index.html` 1ファイルで動作します（サーバー・外部ライブラリ不要）。

## 入力項目（フル版との違い）

| 項目 | かんたん版 | フル版 |
|---|---|---|
| 地域区分 | 1〜8 を選択 | 同じ |
| 断熱性能 | 無断熱／等級3〜7 のカード | 同じ＋窓の個別選択・U値直接入力 |
| 広さ | 80/100/120/150㎡ ボタン | 数値入力も可 |
| 階数 | 1〜3 | 同じ |
| 窓 | 南面の大きさを3段階（少なめ/ふつう/多め）。東西北は固定 | 方位×3種類の個数・寸法 |
| 庇 | なし/60cm/90cm（全方位） | 深さ5段階＋方位指定 |
| 日よけ | なし／南東西に外付けスクリーン相当 | 方位ごとに4種類 |
| 隣の建物 | なし（固定） | 方位ごとに距離・高さ |
| 換気・通風 | 固定 | 熱交換換気・夏の窓開け通風 |
| 比較対象 | 「同じ家を等級○で建てた場合」 | 同じ＋保存した任意条件 |
| 結果 | 中学生向けの「結果シート」：一言の判定（顔アイコン）、家2軒の比較バー（比べる家＝100）、身近なたとえ（ふつうの家の電気○か月分・スギの木○本分・電気代差）、S〜Dの成績目盛り、5月・11月の温度計 | 差分％カード・月別グラフ・熱の逃げ方・方位別日射・詳細表 |

固定値：東面＝腰窓1＋小窓1、西面＝同、北面＝腰窓1＋小窓2、平面は東西1.25:1、階高2.8 m、
第三種換気、窓は閉め切り、電気31円/kWh、COP 暖房3.0/冷房3.5、CO2 0.434 kg/kWh。

## ビルド（エンジンの共有）

計算エンジンはフル版 `passive_house_calc/index.html` の
`/* ==== ENGINE START ==== */` 〜 `/* ==== ENGINE END ==== */` のブロックを唯一の原本とし、
`build.ps1` が `src/lite_template.html` の `<!-- ENGINE -->` に差し込んで `index.html` を生成します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File passive_house_calc_lite\build.ps1
```

- フル版のエンジン（気象値・U値・計算式）を変更したら、このコマンドを再実行して簡易版を更新してください。
- 画面や文言を変えるときは `src/lite_template.html` を編集し、`index.html` は直接編集しないでください（ビルドで上書きされます）。
- ローカル確認は `.claude/launch.json` の `passive-calc-lite`（port 8767）。

## 公開時の注意

- 個人情報は扱いません。入力条件はURLの `#s=` に入るだけで、サーバーには何も送信しません。
- 結果はあくまで目安である旨（「計算の前提と注意」）を折りたたみで表示しています。
- 「詳細版もあります」の一文はリンクなしにしてあります。フル版の配布先だけに案内する運用を想定しています。
